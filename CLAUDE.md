# Global instructions

## Coding rules

Apply these four rules to all code work:

1. Think before coding. State assumptions. Ask when the request is unclear.
2. Simplicity first. Write the minimum code that solves the problem.
3. Surgical changes. Change only the lines that the request needs.
4. Goal-driven execution. Define a success check and run it before you report that the task is done.

## Git

Never add `Co-Authored-By: Claude` or any other Claude or Anthropic attribution to commits or pull requests.
